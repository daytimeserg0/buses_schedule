# Buses Schedule

Учебный проект на Python для моделирования автобусного маршрута и подбора расписания водителей генетическим алгоритмом. Симуляция учитывает движение автобусов, пассажиропоток, рабочие смены и перерывы, а Matplotlib отображает маршрут и состояние транспорта.

## Возможности

- Симуляция одной недели работы маршрута с 28 остановками и двумя конечными станциями.
- Моделирование посадки и высадки пассажиров, вместимости автобусов и ожидания на остановках.
- Два типа графиков водителей с учётом смен и перерывов.
- Пауза, изменение скорости, добавление автобусов и водителей через графический интерфейс.
- Подсчёт недовольных пассажиров и условных затрат на автобусы и водителей.
- Генетический подбор расписания: создание популяции, отбор, скрещивание и мутации. Критерий оценки — уменьшение числа недовольных пассажиров.

## Технологии и навыки

**Python, Matplotlib, Tkinter, ООП, имитационное моделирование, генетические алгоритмы.**

Для backend-портфолио проект показывает работу с предметной логикой: моделирование сущностей и их состояний, реализацию правил смен и ограничений вместимости, обработку временных событий и оценку решений по числовой метрике. Приложение запускается локально с графическим интерфейсом.

## Запуск

Нужен Python 3.11+ с поддержкой Tkinter и графическая среда. В стандартном установщике Python для Windows компонент Tcl/Tk обычно включён; в Linux он может устанавливаться отдельно, например пакетом `python3-tk` в Ubuntu/Debian.

```bash
git clone https://github.com/daytimeserg0/buses_schedule.git
cd buses_schedule
python -m venv .venv
```

Windows / PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install matplotlib
.\.venv\Scripts\python.exe buses.py
```

Linux / macOS:

```bash
.venv/bin/python -m pip install matplotlib
.venv/bin/python buses.py
```

Вся логика находится в `buses.py`. Начальные данные заданы в списках `driver_list` и `bus_list`: 10 водителей и 8 автобусов.

## Работа с приложением

После запуска открывается визуализация недельной симуляции. Кнопки в окне:

| Кнопка | Действие |
| --- | --- |
| `Pause/Continue` | Приостановить или продолжить симуляцию |
| `Enter speed` | Изменить скорость анимации |
| `Add Bus` | Добавить автобус на выбранную конечную станцию |
| `Add Driver` | Добавить водителя и задать его график |
| `Drivers List` | Посмотреть список водителей и смен |

После завершения симуляции автоматически начинается генетический подбор расписания: по умолчанию 100 поколений с популяцией из 100 вариантов. Ход поиска и итоговое расписание выводятся в консоль.

## Особенности

Недельная анимация и последующий перебор расписаний могут занимать значительное время. Пассажиропоток и поиск используют случайные значения, поэтому результаты разных запусков отличаются. Подбор расписания оценивает число недовольных пассажиров; рассчитанные затраты не входят в критерий оптимизации.

Состояние хранится в памяти на время запуска. Это модель с условными маршрутами, спросом и стоимостью ресурсов.
